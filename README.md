# 🚀 Estudos de JavaScript — Web 2

📚 Repositório destinado aos estudos, exercícios e projetos desenvolvidos na disciplina de **Web 2**, durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

💻 O objetivo deste repositório é registrar minha evolução no aprendizado de **JavaScript**, explorando desde os fundamentos da linguagem até sua integração com **HTML e CSS** para a criação de páginas e aplicações web interativas.

## 📌 Conteúdos estudados

🟨 **JavaScript**
- 🔤 Variáveis e tipos de dados
- ➕ Operadores e expressões
- ⌨️ Entrada e saída de dados
- 🔀 Estruturas condicionais
- 🔁 Estruturas de repetição
- ⚙️ Funções
- 📦 Arrays e objetos
- 🌐 Manipulação do DOM
- 🖱️ Eventos e interações
- 🔗 Integração entre HTML, CSS e JavaScript

## 🛠️ Tecnologias

- 🟨 JavaScript
- 🌐 HTML5
- 🎨 CSS3
- 🐙 Git & GitHub

## 🎯 Objetivo

Construir uma base sólida em **desenvolvimento web**, colocando os conceitos estudados em prática por meio de exercícios e pequenos projetos.

> 💡 **Aprender, praticar, errar, corrigir e evoluir.**  
> 🚀 Este repositório representa minha jornada de aprendizado em desenvolvimento web.
